# Design-Referenz

Ablage für Screenshots und Moodboards als **Inspiration**, z. B. von Neotaste (Hauptvorbild: lebendig, urban, Deals im Vordergrund) sowie Uber, Wise und Airbnb (Klarheit).

## Regeln

- Nur zur Orientierung für Layout, Informationshierarchie und Interaktionen.
- **Nichts übernehmen:** keine Logos, Markenfarben, Illustrationen, Icons oder Texte anderer Apps. Wir haben eine eigene Identität (Akzent „Gold“, siehe `packages/shared/src/tokens`).
- Dateinamen: `<app>-<screen>-<kurzbeschreibung>.png`, z. B. `neotaste-feed-karten.png`
- Pro Screenshot gern eine Zeile in der Liste unten: Was gefällt uns daran?
- Das Repo ist öffentlich. Deshalb nur eigene Screenshots ablegen und keine Bilder mit personenbezogenen Daten.
